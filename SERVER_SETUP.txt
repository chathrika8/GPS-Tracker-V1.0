================================================================
  GPS Tracker V1.1 — Cloudflare Worker + Supabase Setup
================================================================

This is the server-side counterpart to the firmware on this branch
(claude/optimize-2g-performance-tvWaR). The firmware sends a compact
binary frame over plain HTTP. The previous Worker only understood the
old verbose JSON format, so it must be replaced with the script below.

The new Worker is a drop-in replacement for the previous one:

  * Keeps SUPABASE_URL and the anon key INLINE in the file (same style
    as the previous Worker; no env vars to set).
  * Keeps the catch-all pass-through to /rest/v1/<anything> so the
    OTA fetch and command poller keep working.
  * Adds POST /uplink for the new binary frame and the new short-key
    JSON, AND still accepts the old verbose JSON so devices that
    haven't been re-flashed yet keep working.
  * Maps every payload format to the SAME Supabase row shape your
    existing dashboard already understands (timestamp ISO-8601,
    fw_version included).

There is NO /agps route. AssistNow Online was removed entirely
because u-blox stopped issuing tokens on 3 June 2025 and the free
replacement (Predictive Orbits) only supports Gen9/Gen10 modules,
not the Gen6 NEO-6M. The firmware uses an on-device ephemeris cache
plus AT+CIPGSMLOC cell-tower seeding to get fast TTFF without any
external service — see README "AGPS — local cache + cell-tower seed".

-----------------------------------------------------------------
  REQUEST FLOW
-----------------------------------------------------------------

   Device                         Cloudflare Worker             Supabase
   ──────                         ─────────────────             ─────────────────
   POST /uplink   ──────►         decode binary OR              POST /rest/v1/locations
   (octet-stream                  short-key JSON OR             (HTTPS, anon key)
   or any JSON)                   verbose JSON, expand     ───► Supabase
                                  batch → N rows

   * /anything    ──────►         prefix /rest/v1/, forward
                                  with anon key                  ───► Supabase REST

-----------------------------------------------------------------
  WHAT YOU NEED TO PASTE INTO THE WORKER
-----------------------------------------------------------------

Only ONE thing is mandatory:

  DEVICE_MAP        optional: maps the FNV-1a hash of each device's
                    DEVICE_ID back to the human-readable string.

To compute the hash for "GPS-001":

  printf "GPS-001" | python3 -c '
  import sys
  h = 2166136261
  for b in sys.stdin.buffer.read():
      h = ((h ^ b) * 16777619) & 0xFFFFFFFF
  print("0x%08x" % h)
  '

If a hash isn't in DEVICE_MAP, the Worker stores the raw hex hash in
device_id so nothing is silently dropped.

The SUPABASE_URL and SUPABASE_KEY constants stay where they were in
the previous Worker — exactly the same anon key, no rotation needed.

// gps-tracker-worker.js
// Cloudflare Worker for GPS-Tracker-V1.0 firmware (handles v1.0.x and v1.1.x).

const SUPABASE_URL = 'https://wwsiimmmkrhieumkrkhq.supabase.co';
const SUPABASE_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6Ind3c2lpbW1ta3JoaWV1bWtya2hxIiwicm9sZSI6ImFub24iLCJpYXQiOjE3NzQyMzg2NTcsImV4cCI6MjA4OTgxNDY1N30.9sPJnJZnWssEwX9TJUQ_p6Pi3MJk_RuP-lgO9NPk1kY';

// Optional: device_id hash → friendly name. Leave {} to fall back to hex.
const DEVICE_MAP = {
  // '0xc0ffee01': 'GPS-001',
};

// Used as the fw_version on rows decoded from the binary frame, which
// doesn't carry a version string of its own.
const BIN_FW_FALLBACK = '1.1.0';

const HEADER_LEN = 11;
const PACKET_LEN = 20;

const SUPA_HEADERS = {
  'apikey':        SUPABASE_KEY,
  'Authorization': `Bearer ${SUPABASE_KEY}`,
  'Content-Type':  'application/json',
  'Prefer':        'return=minimal',
};

export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);

    if (url.pathname === '/uplink' && request.method === 'POST') {
      return handleUplink(request);
    }
    if (url.pathname === '/health') {
      return new Response('ok', { status: 200 });
    }

    // Pass-through for everything else (commands, OTA, dashboard reads).
    return handlePassthrough(request, url);
  },
};

// ─── /uplink ────────────────────────────────────────────────────
async function handleUplink(request) {
  const ct = (request.headers.get('content-type') || '').toLowerCase();
  let rows;
  try {
    if (ct.includes('application/octet-stream')) {
      const buf = new Uint8Array(await request.arrayBuffer());
      rows = decodeBinary(buf);
    } else {
      // Both the new short-key and the old verbose JSON land here.
      const body = await request.json();
      rows = decodeAnyJson(body);
    }
  } catch (e) {
    return new Response(`DECODE: ${e.message}`, { status: 400 });
  }

  if (!rows.length) return new Response('OK (empty)', { status: 200 });

  const r = await fetch(`${SUPABASE_URL}/rest/v1/locations`, {
    method:  'POST',
    headers: SUPA_HEADERS,
    body:    JSON.stringify(rows),
  });
  if (!r.ok) {
    const t = await r.text();
    return new Response(`SUPABASE: ${t}`, { status: r.status });
  }
  return new Response(`OK (${rows.length})`, { status: 200 });
}

// ─── Generic pass-through (commands, OTA, dashboard reads) ─────
async function handlePassthrough(request, url) {
  try {
    let path = url.pathname;
    if (!path.startsWith('/rest/v1/')) {
      path = '/rest/v1/' + path.replace(/^\//, '');
    }
    const targetUrl = `${SUPABASE_URL}${path}${url.search}`;
    const opts = { method: request.method, headers: SUPA_HEADERS };
    if (request.method !== 'GET' && request.method !== 'HEAD') {
      opts.body = await request.text();
    }
    const r = await fetch(targetUrl, opts);
    if (!r.ok) {
      const t = await r.text();
      return new Response(`SUPABASE: ${t}`, { status: r.status });
    }
    return new Response(r.body, { status: r.status });
  } catch (e) {
    return new Response(`PROXY ERROR: ${e.message}`, { status: 500 });
  }
}

// ─── Binary decoder ─────────────────────────────────────────────
// Layout (all little-endian):
//   Header (11 B): 'G' | ver=1 | device_hash u32 | buf_count u32 | n u8
//   Per packet (20 B): ts u32 | lat i32×1e7 | lon i32×1e7 | alt i16
//                       | speed u8×0.5 | course u8×2 | sats u8
//                       | hdop u8/10 | gsm u8 | batt u8 (3.0+x/100)
function decodeBinary(buf) {
  if (buf.length < HEADER_LEN) throw new Error('header truncated');
  if (buf[0] !== 0x47)         throw new Error(`magic: ${buf[0].toString(16)}`);
  if (buf[1] !== 0x01)         throw new Error(`version: ${buf[1]}`);

  const dv = new DataView(buf.buffer, buf.byteOffset, buf.byteLength);
  const deviceHash = dv.getUint32(2, true);
  const n          = buf[10];
  if (buf.length < HEADER_LEN + n * PACKET_LEN) {
    throw new Error(`body truncated: ${buf.length} < ${HEADER_LEN + n * PACKET_LEN}`);
  }
  const deviceId = resolveDevice(deviceHash);

  const rows = [];
  for (let i = 0; i < n; i++) {
    const o = HEADER_LEN + i * PACKET_LEN;
    rows.push({
      device_id : deviceId,
      fw_version: BIN_FW_FALLBACK,
      timestamp : new Date(dv.getUint32(o + 0, true) * 1000).toISOString(),
      latitude  : dv.getInt32 (o + 4, true) / 1e7,
      longitude : dv.getInt32 (o + 8, true) / 1e7,
      altitude_m: dv.getInt16 (o + 12, true),
      speed_kmh : buf[o + 14] / 2.0,
      course    : buf[o + 15] * 2.0,
      satellites: buf[o + 16],
      hdop      : buf[o + 17] / 10.0,
      gsm_signal: buf[o + 18],
      battery_v : 3.0 + buf[o + 19] / 100.0,
    });
  }
  return rows;
}

// ─── JSON decoder (short-key v1.1 + verbose legacy v1.0) ───────
function decodeAnyJson(body) {
  if (!body || typeof body !== 'object') throw new Error('not an object');

  // Detect format by the array key. v1.1 uses "p", v1.0 used "packets".
  if (Array.isArray(body.p)) {
    const deviceId  = String(body.d || 'unknown');
    const fwVersion = String(body.f || BIN_FW_FALLBACK);
    return body.p
      .filter(r => Array.isArray(r) && r.length >= 10)
      .map(r => ({
        device_id : deviceId,
        fw_version: fwVersion,
        timestamp : new Date(r[0] * 1000).toISOString(),
        latitude  : r[1],
        longitude : r[2],
        altitude_m: r[3],
        speed_kmh : r[4],
        course    : r[5],
        satellites: r[6],
        hdop      : r[7],
        gsm_signal: r[8],
        battery_v : r[9],
      }));
  }

  if (Array.isArray(body.packets)) {
    const deviceId  = String(body.device_id || 'unknown');
    const fwVersion = String(body.fw_ver || BIN_FW_FALLBACK);
    return body.packets.map(p => ({
      device_id : deviceId,
      fw_version: fwVersion,
      timestamp : new Date(p.ts * 1000).toISOString(),
      latitude  : p.lat,
      longitude : p.lon,
      altitude_m: p.alt_m,
      speed_kmh : p.speed_kmh,
      course    : p.course,
      satellites: p.sats,
      hdop      : p.hdop,
      gsm_signal: p.gsm_signal,
      battery_v : p.batt_v,
    }));
  }

  throw new Error('no "p" or "packets" array');
}

// ─── Device hash → friendly id ──────────────────────────────────
function resolveDevice(hash) {
  const hex = '0x' + hash.toString(16).padStart(8, '0');
  return DEVICE_MAP[hex] || hex;
}

-----------------------------------------------------------------
  SUPABASE — NO SCHEMA CHANGE REQUIRED
-----------------------------------------------------------------

Your existing locations table is fully compatible with this Worker.
The Worker emits exactly the same column shape your previous one did
(device_id, fw_version, timestamp ISO-8601, latitude, longitude,
altitude_m, speed_kmh, course, satellites, hdop, gsm_signal,
battery_v). No NULLs in any column, no schema change required.

The optional buf_depth and created_at columns suggested in earlier
revisions of this file have been dropped from the default Worker code
to keep the row shape byte-for-byte identical to your current rows.
If you want them later, ALTER TABLE ... ADD COLUMN IF NOT EXISTS is
safe to run alongside an updated Worker that emits those fields.

-----------------------------------------------------------------
  STEP-BY-STEP DEPLOY
-----------------------------------------------------------------

  1. Cloudflare → Workers & Pages → your Worker → Edit Code, replace
     the contents with the JS block above.
  2. Optional: fill in DEVICE_MAP with your device IDs.
  3. Save and Deploy.
  4. Smoke tests:
        curl https://api.<yourdomain>.com/health     # → "ok"
        # Old-format JSON should still ingest:
        curl -X POST https://api.<yourdomain>.com/uplink \
             -H 'Content-Type: application/json' \
             -d '{"device_id":"GPS-001","fw_ver":"1.0.0",
                  "packets":[{"ts":1714000000,"lat":6.9271,"lon":79.8612,
                  "alt_m":10,"speed_kmh":0,"course":0,"sats":7,
                  "hdop":1.2,"gsm_signal":80,"batt_v":3.9}]}'
  5. Flash the firmware on this branch and watch the Worker logs
     (Logs → Live tail). Expect one POST every ~5 s with "OK (5)".

-----------------------------------------------------------------
  ROLLBACK
-----------------------------------------------------------------

If anything goes wrong, the previous Worker version is one click away
in Workers → your Worker → Deployments. The firmware on the device
retries on the next cycle, so no data is permanently lost beyond the
in-flight batch.
